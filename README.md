# MedXpert 医械注册实务知识库（公开源）

本仓库是知乎直答「医械注册实务」知识库的公开同源源（SSOT）。内容由 MedXpert 个人监管知识项目整理，覆盖：

- `qms-gmp2025/`：医疗器械 QMS 与 GMP2025 合规
- `clinical-eval/`：临床评价与 CER
- `registration-ops/`：注册运营、国际准入、AI 器械合规、ISO 13485
- `translation/`：医械法规中英翻译（含术语对照表与文档翻译要点）

> 说明：本仓库为公开知识源，不含任何商业敏感信息、客户信息或雇主标识。内容仅供学习交流，不构成法规咨询意见；具体注册以官方最新要求为准。
