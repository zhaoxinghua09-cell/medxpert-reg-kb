# 医械文档类型翻译要点（翻译专用）

> 来源：medical-device-reg-hub 图书馆枢纽提炼。翻译前先判断文档类型，按对应要点处理。
> 术语依据导航见 `图书馆导航表.md`（翻译什么文档 → 查哪个枢纽）。

## 一、IFU / 使用说明书

**监管依据**：中国（说明书标签规定）、FDA 21 CFR 801、EU MDR Annex I 23.1（标签与说明书要求）

**翻译要点**：
- **结构要素**：预期用途 → 适用人群 → 禁忌 → 警告 → 注意事项 → 操作说明 → 维护保养 → 储存 → 处置 → 制造商信息
- 中文"说明书"→ 英文视语境：IFU（Instructions for Use）或 User Manual
- 警示框（WARNING/CAUTION）格式保留，**语义不弱化**
- 多语言版本：同一文档多语言并存时，保持各语言内容一致、版本号同步
- 数值单位：mm/cm、mL、°C 等保留原单位，不换算
- 图示标注文字需对应翻译（图中文字要译）

**常见坑**：
- "本品仅供一次性使用" → "For single use only"（或 Single use only），勿译成 "one-time use"
- "请在医生指导下使用" → "Use under the guidance of a physician"（勿直译 "under the guidance of a doctor" 也可以，但 physician 更正式）
- "失效日期" → "Use by" / "Expiry date"，注意区分 "生产日期 Manufacture date"
- ⚠️ **ISO 20417 版本坑**：旧资料常写 "ISO 20417:2021"，但该版已撤消（Withdrawn），**现行版本为 ISO 20417:2026**——翻译引用标准号时避免写错版本；符号类用 ISO 15223-1:2021
- ⚠️ 灭菌信息（方法/有效期/再处理）是复用/无菌器械 IFU 的翻译重点；灭菌标准归口 ISO/TC 198

## 二、FDA 510(k) 提交文件

**监管依据**：21 CFR Part 807 Subpart E；eSTAR 格式

**翻译要点**：
- 标准章节结构：Cover Letter → 510(k) Summary → 设备描述 → 实质等同性对比 → 测试数据摘要 → 标签
- 产品代码（Product Code）、法规编号（CFR citation）**原样保留不译**
- "substantial equivalence" → "实质等同性"（固定译法）
- "predicate device" → "对比器械"（固定译法，勿译"谓词设备"）
- "510(k) Summary" → 保留英文（美国提交物，中文翻译供内部参考时可译为"510(k) 摘要"）

**常见坑**：
- "clearance"（FDA 许可上市）≠ "approval"（FDA 批准，用于 PMA）——**510(k) 用 clearance，PMA 用 approval**，翻译时严格区分
- "indications for use" 与 "intended use" 在 510(k) 中是两个字段，勿合并
- 510(k) Summary 必备内容（21 CFR 807.92）：器械名称/分类/预期用途、predicate 对比、技术特征、性能数据摘要、标准符合性、标签要点——翻译时这些章节都要有
- 基础手动复用器械（如部分外科钳）属 Class I 豁免 510(k)，无需 Summary——翻译背景文档时注意别张冠李戴

## 三、CE MDR 技术文件

**监管依据**：EU MDR 2017/745 Annex II（技术文件）

**翻译要点**：
- 章节：设备描述 → GSPR 符合性 → 风险利益分析 → 临床评价 → 标签与说明书 → DoC
- "General Safety and Performance Requirements (GSPR)" → "通用安全与性能要求"
- "Technical Documentation" → "技术文件"
- "Declaration of Conformity (DoC)" → "符合性声明"
- "periodic safety update report (PSUR)" → "定期安全更新报告"
- 欧盟代表（Authorized Representative / EU Representative）术语统一

**常见坑**：
- MDR 用 "performance"（性能）的地方不要译成 "performance" 乱用；GSPR 是"性能要求"语境
- "conformity assessment" → "符合性评定"（欧盟术语），≠ 中国的"注册检验"或"体系核查"
- MDR Annex II 六章：1 器械描述与规格 / 2 标签与IFU / 3 设计与制造 / 4 GSPR符合性 / 5 获益-风险与风险管理 / 6 验证与确认——翻译时保持章节编号对应
- IIb/III 类需 SSCP（安全与临床性能摘要）公示——翻译时勿与 CER 混淆

## 四、标签（Label / Labeling）

**监管依据**：FDA 21 CFR 801、MDR Annex I 23、中国说明书标签规定

**翻译要点**：
- 标签要素：制造商名称地址 → 产品名称 → 型号规格 → 批号/序列号 → UDI → 生产日期 → 有效期 → 储存条件 → CE 标志（如适用）
- "labeling"（广义，含说明书包装）vs "label"（狭义标签）区分
- UDI 载体（Data Matrix 码）文字标注翻译

**常见坑**：
- "Made in China" 保留英文，不译
- 符号（Symbols）：ISO 15223-1 医疗器械符号，图符保留，标题文字翻译

## 五、临床评价 / 临床报告

**监管依据**：MDR Article 61、MDCG 2020-13；中国《医疗器械临床评价技术指导原则》

**翻译要点**：
- "clinical evaluation" → "临床评价"（MDR 路径）vs "clinical trial" → "临床试验"（中国术语"临床评价"含三路径）
- 中国语境：同品种比对 → "same-type comparison"；豁免临床 → "exempt from clinical trials"
- CER（Clinical Evaluation Report）→ "临床评价报告"
- 统计学术语（显著性、置信区间、p 值）标准译法

**常见坑**：
- "clinical investigation"（欧盟术语=临床试验）勿译成"临床调查"
- 中国"临床试验豁免" ≠ 欧盟"临床豁免"（概念不同，翻译时标注市场语境）
- **三市场等同性术语对应**：中国"同品种比对" = FDA "实质等同 (Substantial Equivalence)" = MDR "等同性 (Equivalence)"——翻译按目标市场转换，不混用
- 中国免临床目录：2025 年版（2025 年第 19 号公告，1047 项）取代 2023 年版——翻译目录引用时注意版本
- CER 撰写五要点：文献检索方案 / 等同性论证 / 数据来源三角（文献+临床经验+试验）/ 与风险管理呼应 / 欧盟按 MDCG 2020-13 模板——翻译 CER 时术语对齐这些要素

## 六、质量体系文档（GMP / ISO 13485）

**监管依据**：ISO 13485、中国 GMP、FDA QMSR（21 CFR Part 820）

**翻译要点**：
- "quality management system" → "质量管理体系"
- 过程确认（Process Validation）的 IQ/OQ/PQ 三阶段保留英文缩写，中文注释
- "device master record" → "器械主记录"（FDA 术语）
- "nonconformity" → "不合格"（体系术语）
- 程序文件/作业指导书：SOP、Work Instruction 术语区分

**常见坑**：
- "validation" 在体系文档中多为"确认"（process validation=过程确认），在软件语境为"验证"（software validation=软件验证）——按语境选择
- "corrective and preventive action (CAPA)" → "纠正和预防措施"（固定译法）

## 七、出口销售证明 / 注册证文件

**监管依据**：2026-05 出口销售证明新规（中国）

**翻译要点**：
- "Certificate of Free Sale" → "自由销售证书"
- "Export Certificate / Certificate for Export" → "出口销售证明"
- 注册证："Medical Device Registration Certificate" → "医疗器械注册证"
- 备案凭证："Filing Certificate" → "备案凭证"

## 八、STED 技术文档（IMDRF 国际协调格式）

**监管依据**：IMDRF/GHTF SG1 N011（国际协调格式，美/欧/日/加/澳多国认可）

**翻译要点**：
- **STED 六章结构**：1 器械描述与规格 / 2 基本信息（标签） / 3 设计与制造 / 4 通用安全性能原则(EP) / 5 风险分析 / 6 验证与确认——翻译时保持六章编号
- "Summary Technical Documentation" → "技术文档摘要"（STED）；欧盟"Technical Documentation"= 技术文档（Annex II），二者层级不同
- STED 是中轴格式，各国再映射裁剪——翻译时标注目标市场章节映射

## 九、UDI / 唯一标识文件

**监管依据**：中国 2019 年第 66 号公告、FDA 21 CFR 830、MDR Art.27、日本药机法

**翻译要点**：
- **DI / PI 区分**：DI（Device Identifier）= 器械标识（产品级）；PI（Production Identifier）= 生产标识（批次/序列/日期）——翻译时术语精确，勿混
- "Labeler"（美国）= 标签方（责任方），≠ 制造商
- "Basic UDI-DI"（欧盟）= 基本 UDI-DI（模型级），与 UDI-DI（产品单元级）不同——欧盟特有，注意区分
- 发码机构：GS1 / HIBCC / ICCBBA（保留不译）
- 美国 GUDID（唯一标识数据库）、欧盟 EUDAMED、中国 UDI 数据库（udi.nmpa.gov.cn）、日本 KikiDB——数据库名保留

## 十、翻译通用检查清单（每次交付前过一遍）

- [ ] 标准号/法规名/机构名原样保留（ISO 13485、FDA、MDR）
- [ ] 数值、单位、型号、批号未改动
- [ ] WARNING/CAUTION 语义未弱化
- [ ] 同一术语全文一致（用术语表约束）
- [ ] 中国/美国/欧盟语境术语区分（如 clearance vs approval、临床评价 vs 临床试验）
- [ ] 表格、编号、章节结构保留
- [ ] 不确定项已标 `[待核]` 并说明
- [ ] 交付附术语表 + 翻译日期 + "以官方最新法规为准"声明
