## 三、翻译术语重点补强（从新读枢纽提炼，补充术语表）





### 风险管理（ISO 14971）


- hazard → 危害（源）；harm → 伤害；hazardous situation → 危险情况


- risk analysis / evaluation / control → 风险分析 / 评价 / 控制


- residual risk → 剩余风险；risk-benefit analysis → 获益-风险分析


- foreseeable misuse → 可合理预见的误用


- 中国标准名：GB/T 42062-2022（风险管理）、ISO/TR 24971（应用指南）





### GMP / 质量体系（ISO 13485）


- quality management system → 质量管理体系（QMS）


- process validation → 过程确认；design verification/validation → 设计验证/设计确认


- IQ/OQ/PQ → 安装确认/运行确认/性能确认（缩写保留，中文注释）


- cleanroom → 洁净室；sterile barrier → 无菌屏障


- reprocessing → 再处理；bioburden → 生物负载


- CAPA（corrective and preventive action）→ 纠正和预防措施


- PIC/S GMP、AAMI ST98（清洁验证）、ASTM F3127（清洁度评估）→ 保留原样





### 灭菌（ISO 11135/11137/17665）


- EO sterilization → 环氧乙烷灭菌；irradiation → 辐照灭菌；moist heat → 湿热灭菌


- sterility assurance level (SAL) → 无菌保证水平（SAL ≤ 10⁻⁶ 不译）


- parametric release → 参数发布；product release → 产品发布


- overkill method → 过度杀灭法；bioburden method → 生物负载法


- biological indicator (BI) → 生物指示剂


- 中国标准：GB 18279（=ISO 11135）、GB 18280（=ISO 11137）、GB 18278（=ISO 17665）





### 生物相容性（ISO 10993）


- biocompatibility → 生物相容性；biological evaluation → 生物学评价


- cytotoxicity → 细胞毒性；sensitization → 致敏；irritation → 刺激


- hemocompatibility → 血液相容性；genotoxicity → 遗传毒性


- chemical characterization → 化学表征；extractable → 可沥滤物


- material characterization → 材料表征


- 中国标准：GB/T 16886.1-2022（等同 ISO 10993-1:2018）；ISO 10993-1:2025 为国际最新


- 终点选择矩阵：表面接触/外部接入/植入 × 接触时间 → 对应试验终点





### 软件与人因（IEC 62304/62366）


- software as a medical device (SaMD) → 医疗器械软件（独立软件）


- software lifecycle → 软件生命周期；legacy software → 遗留软件


- usability engineering → 可用性工程；human factors → 人因工程


- use error → 使用错误；formative evaluation → 形成性评估；summative evaluation → 总结性评估


- SOUP（software of unknown provenance）→ 第三方软件（保留 SOUP）


- SBOM（software bill of materials）→ 软件物料清单


- FDA 三级关注：Major/Moderate/Minor（保留英文）


- cybersecurity → 网络安全；MDCG 2019-16（网络安全指南）





### 设计开发（ISO 13485 7.3 / 21 CFR 820.30）


- design input / output → 设计输入 / 输出


- design review → 设计评审；design transfer → 设计转移


- **verification vs validation 区分**：verification=设计验证（做对了没有，对规格）；validation=设计确认（做对了产品没有，对用户）——翻译按语境


- device history record (DHR) → 器械历史记录；device master record (DMR) → 器械主记录





### 注册申报（eRPS/eSTAR/EUDAMED）


- eRPS（中国电子申报）、eSTAR（FDA 电子模板）、EUDAMED（欧盟数据库）、SRN（单一注册号）→ 保留


- MDUFA 费用、小企业减免 → 保留


- Pre-Sub（预提交会议）→ 保留；RTA（拒绝接受）→ 保留


- 发补（中国补正/美国缺陷信/欧盟 NB 意见）→ 按市场语境译





### 上市后监管（PMS）


- post-market surveillance (PMS) → 上市后监督


- periodic safety update report (PSUR) → 定期安全更新报告


- field safety corrective action (FSCA) → 现场安全纠正措施（欧盟）


- post-market clinical follow-up (PMCF) → 上市后临床跟踪


- **美国称 Recall、欧盟称 FSCA、中国称 召回**——翻译按目标市场转换


- 不良事件 → adverse event（美国 FDA 语境）；警戒 → vigilance（欧盟语境）


- trend report → 趋势报告（MDR Art.88）





### 变更与延续（47 号令 / 807.81 / MDCG 2020-3）


- 变更注册 / 变更备案 → change registration / record change（中国语境）


- 延续注册 → renewal of registration（届满前 6 个月）


- new 510(k) → 新 510(k)（影响 SE 的变更触发）


- significant change → 重大变更（欧盟 MDCG 2020-3）





### 市场准入与销售


- 经营许可 / 经营备案 → operation license / operation filing（中国）


- 出口销售证明 → Export Certificate（2026-05 新规：证明(I)/(II)）


- Establishment Registration & Device Listing → 企业注册与器械列名（FDA）


- 集采 → centralized procurement；挂网 → online listing（医院采购）


- EC REP（欧盟授权代表）、US Agent（美国代理人）→ 保留





### MAH / 委托生产


- marketing authorization holder (MAH) → 注册人（中国语境）；制造販売業者（日本，保留日文）


- entrusted production → 委托生产；quality agreement → 质量协议


- 禁止委托生产目录 → prohibited list for entrusted production


- 生产放行 / 上市放行 → production release / market release





## 四、翻译决策规则补充（图书馆共识）





1. **版本必查**：标准号引用前查「法规版本时效速查」——ISO 20417、10993-1 等已更新版本，写错版本=交付事故


2. **术语按市场转换**：同一概念不同市场叫法不同（召回 Recall/FSCA/召回；临床评价 clinical evaluation/同品种比对/实质等同）——按目标市场选择


3. **缩写保留原则**：eRPS/eSTAR/EUDAMED/SRN/SOUP/SBOM/SAL/IQ/OQ/PQ/DI/PI/UDI 等专业缩写原样保留，中文注释首现


4. **机构名保留**：NMPA/FDA/PMDA/Notified Body/CMDE/ANVISA/COFEPRIS 不译


5. **标准号保留**：ISO/GB/T/YY/EN/IEC/ASTM 系列原样保留，不翻译


6. **警示语义**：WARNING/CAUTION 等只可等值或增强，不可弱化（跨所有文档类型）


7. **数值单位**：SAL 10⁻⁶、kGy、温度、残留限量等严格保留不换算
