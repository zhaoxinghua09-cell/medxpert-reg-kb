## 四、枢纽中的术语坑速查（翻译易错点）

| 枢纽 | 易错术语 | 正确译法 |
|---|---|---|
| 标签与IFU | ISO 20417 版本 | ⚠️ **2021 版已撤消，现行为 ISO 20417:2026**——翻译引用时避免写错版本 |
| 标签与IFU | 符号 vs 文字 | ISO 15223-1 符号保留，标题文字翻译 |
| STED | Technical Documentation | 欧盟=技术文档；STED=技术文档摘要（IMDRF 格式） |
| 临床评价 | clinical evaluation vs clinical trial | 临床评价（MDR 路径）vs 临床试验；临床调查=clinical investigation |
| 临床评价 | 同品种比对 vs 实质等同 | 中国"同品种比对" = FDA"实质等同(SE)" = MDR"等同性(Equivalence)"——翻译时按市场转换 |
| UDI | DI / PI | DI=器械标识（产品级）、PI=生产标识（批次/序列/日期） |
| GMP | validation vs verification | 过程确认（process validation）vs 设计验证（design verification）——validation 按语境 |
| 风险管理 | hazard vs harm | 危害（源）vs 伤害——勿混 |
| 灭菌 | 灭菌 vs 无菌 | sterilization=灭菌（过程）、sterile=无菌（状态） |

## 五、调用方式

翻译任务中需要法规依据/术语/结构确认时：
1. 按上表定位枢纽文件
2. 读取对应枢纽（路径：`medical-device-reg-hub` 技能的 `references/` 目录）
3. 提取所需术语/结构/官方链接，用于翻译校对
4. 翻译完成附"术语依据来源"说明（如"术语依据：图书馆《标签与IFU枢纽》"）
