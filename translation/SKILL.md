# 医械法规翻译





> **🌐 官网：https://medxpert.cn/knowledge/**（医械注册知识库·免费公开层）— 法规术语与文档要点在线版。


> **知识底座**：本技能 references 与 `medical-device-reg-hub`（26 枢纽图书馆）同源，法规术语、文档结构、官方链接均以枢纽为准，翻译不凭空猜。





## 这是什么





医械法规文档的**专业翻译与润色工作流**。面向 Fiverr/Upwork 接单交付，也面向日常医械国际业务的中英互译需求。核心差异化：**懂医械法规的翻译**——不是普通翻译，术语、文档结构、法规语境全部对齐监管要求。

## 翻译工作流（核心）





### 流程总览





```


1. 文档分析 → 2. 术语表 → 3. 初译 → 4. 法规术语校对 → 5. 格式还原 → 6. 交付


```





### Step 1: 文档分析


- 判断文档类型（IFU / 510(k) / STED / 标签 / 临床报告 / 质量手册）


- 判断目标市场（NMPA / FDA / EU MDR / PMDA）——决定术语体系和格式要求


- 估算字数、确认交期、识别需保留的专有名词（产品名、型号、标准号）





### Step 2: 术语表（Glossary）


- 先建术语表再翻译，保证全文一致


- 标准号不翻译：ISO 14971、ISO 13485、IEC 60601、ISO 10993、GB/T 16886 原样保留


- 法规名保留官方简称：FDA 510(k)、PMA、De Novo、CE MDR、IVDR、UDI、STED、eSTAR、eRPS


- 专有机构名保留：NMPA、FDA、PMDA、Notified Body、公告机构


- 术语对照见 `references/医械中英术语对照表.md`





### Step 3: 初译


- 忠实原文，不增删含义；技术参数、单位、数值严格保留


- 一句话一个意思，避免中式英语 / 英式中文


- 不确定的术语先标 `[待核]`，不硬翻





### Step 4: 法规术语校对（差异化核心）


- 对照 `references/文档类型翻译要点.md` 逐项检查


- 边界表达：中文"应/宜/可以" ↔ 英文 "shall / should / may" 的规范性差异


- 风险与警告用语：确保警示语义不弱化（WARNING / CAUTION / 禁忌）


- 标准引用格式：中文引用 GB/T ↔ 英文引用 ISO 格式统一





### Step 5: 格式还原


- 保留原文表格、编号、章节结构


- PDF→Word/Excel 交付时还原表格结构


- 交付格式按订单要求（Word / Markdown / 双语对照表）





### Step 6: 交付


- 双语对照或纯目标语言，按客户要求


- 附术语表（含取舍理由）


- 标注"翻译完成日期 + 建议以官方最新法规为准"





## 输出规范





- **译文**：目标语言通顺专业，术语全文一致


- **术语表**：源术语 | 目标术语 | 备注（标准依据/取舍理由）


- **不确定项**：明确标 `[待核]` 并说明原因，不硬翻


- **免责**：译文仅供合规工作参考，不构成法规意见；关键文件建议法规事务（RA）复核





## 注意事项





- 标准号 / 法规名 / 机构名不翻译（见术语表规则）


- 数值、单位、型号严格保留，不得改写


- 涉密文档注意保密；客户名称等敏感信息如需脱敏提前说明


- Fiverr 接单：遵循平台规则（站内沟通、不私下索要联系方式、交付前确认范围）


- 时效：法规会更新，关键内容提示"以官方最新版本为准"





## 错误处理





| 情况 | 处理 |


|---|---|


| 术语拿不准 | 查 `references/医械中英术语对照表.md` + `medical-device-reg-hub` 枢纽；仍无 → 标 `[待核]` 指路官方源 |


| 文档类型不确定 | 看 `references/文档类型翻译要点.md` 判断；拿不准问用户文档用途/目标市场 |


| 客户要求超范围 | 明确告知并建议升级套餐/加价项，不免费扩范围 |


| 法规时效存疑 | 以官方最新发布为准，附核验路径（NMPA/FDA 官网） |

## 图书馆联动（知识底座，2026-08-22 新增）





> **本技能的知识底座 = medical-device-reg-hub 图书馆（26 枢纽）**。翻译不是孤立行为——法规术语、文档结构、官方链接均以图书馆为准。





### 1. 翻译前查导航





- 先读 `references/图书馆导航表.md`，按「文档类型」或「目标市场」定位对应枢纽


- 例如：翻译 IFU → 查 `标签与IFU枢纽.md`；翻译 510(k) → 查 `技术文件STED撰写枢纽.md` + `注册工程师资料枢纽.md`





### 2. 翻译中调枢纽





- 需要法规依据/术语/结构确认时，读取对应枢纽文件（路径：`medical-device-reg-hub` 技能的 `references/` 目录）


- 枢纽内有**官方直达链接**（NMPA/FDA/MDR/PMDA），翻译时可溯源、可复核


- 不确定的术语先查术语表 + 枢纽，仍无 → 标 `[待核]` 指路官方源





### 3. 翻译后附依据





- 关键术语决策附"术语依据来源"（如"术语依据：图书馆《标签与IFU枢纽》"）


- 交付附免责声明：以官方最新发布为准；关键文件建议 RA 复核
